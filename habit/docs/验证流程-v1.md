> 构建状态：✅ 全部通过
> 验证方式：重启 DeskApp 后逐项执行

## ⚠️ 前置条件

1. 确保已构建：`npm run build`（已通过）
2. macOS 需授权「辅助功能」权限（系统设置 → 隐私与安全性 → 辅助功能 → 添加 Electron）
3. 关闭旧 DeskApp：`pkill -f deskapp`

---

## 验证步骤

### V1. 启动与数据库初始化 🟢

```bash
cd ~/deskapp && bash restart.sh
```

**预期**：
- DeskApp 正常启动（宠物出现）
- 控制台日志出现 `[HabitService] initialized — collector running`
- `[HabitCollector] started, interval 5000 ms`

**验证**：
```bash
ls -la ~/Library/Application\ Support/deskapp/habit.db
```
→ 数据库文件存在，大小 > 0

---

### V2. 感知层采集 🟡（需等待 5-15 分钟）

**操作**：正常使用电脑——切换应用、打开网页、敲代码。

**等待**：至少 5 分钟，让采集器运行 ≥ 60 个采样周期。

**验证（终端查询）**：
```bash
sqlite3 ~/Library/Application\ Support/deskapp/habit.db \
  "SELECT COUNT(*) AS events FROM events;
   SELECT COUNT(*) AS segments FROM segments;
   SELECT app, COUNT(*) AS cnt FROM events GROUP BY app ORDER BY cnt DESC LIMIT 5;"
```

**预期**：
- `events` 表 > 0（至少几十条记录）
- `segments` 表 > 0（至少几个活动段）
- 能看到你当前使用的 app 名称

> **如果 events 为 0**：检查辅助功能权限是否已授权，重启 DeskApp 后再试。

---

### V3. 黑名单过滤 🟡

**操作**：打开 1Password 或银行网站，停留 30 秒。

**验证**：
```bash
sqlite3 ~/Library/Application\ Support/deskapp/habit.db \
  "SELECT * FROM events WHERE app LIKE '%Password%' OR url LIKE '%bank%' LIMIT 5;"
```

**预期**：返回空（0 行）——黑名单过滤生效。

---

### V4. 浏览器 URL 采集（macOS）🟡

**操作**：在 Chrome/Safari 中打开任意网站，停留 ≥ 30 秒（URL 采 30s 一次）。

**验证**：
```bash
sqlite3 ~/Library/Application\ Support/deskapp/habit.db \
  "SELECT * FROM events WHERE kind='browser_url' LIMIT 5;"
```

**预期**：至少 1 条 `kind=browser_url` 的记录，`url` 字段有值。

---

### V5. 活动段时间线 🟢

**验证（通过 IPC 查询）**：

在 DeskApp 气泡中执行（等后续 UI 集成后可用）：
```js
// 浏览器 console（bubble 窗口）
const segs = await window.deskAppAPI.habitGetSegments('2026-07-24')
console.log(segs.length, 'segments')
```

**预期**：返回今日活动段数组，每条含 `app`、`title`、`durationMs`。

### V6. 习惯提取 🟡（需使用一段时间后）

**需要**：用电脑至少 1-2 小时，让采集积累足够数据。

**验证**：
```bash
sqlite3 ~/Library/Application\ Support/deskapp/habit.db \
  "SELECT * FROM habits;"
```

或者在气泡 console 中：
```js
const habits = await window.deskAppAPI.habitGetHabits()
console.log(habits)
```

**预期**：
- 如果使用时间短 → 0 张卡是正常的
- 如果有重复行为（如反复切换 VSCode↔Terminal）→ 出现 1-3 张 `candidate` 卡
- 每张卡有 `name`、`kind`、`confidence`、`evidenceCount`

## 问题排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| events 表始终为空 | 辅助功能权限未授权 | 系统设置 → 隐私 → 辅助功能 → 添加 Electron |
| events 有记录但 segments 为空 | 同一 app 未被持续使用 ≥ 5 秒 | 正常：segments 只保留 ≥ 5s 的段 |
| browser_url 始终为空 | AppleScript 权限问题 | 检查 Chrome/Safari 是否允许 AppleScript 访问 |
| 构建报错 `better-sqlite3` | 原生模块未编译 | `npm rebuild better-sqlite3` |
| 日志出现 `EPIPE` | stdout 关闭（正常） | 忽略：app.ts 已处理 |
