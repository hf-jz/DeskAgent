# 习惯工程 (Habit Engineering)

> 让 DeskApp 从"你命令它做事的工具"变成"懂你的伙伴"。

## 定位

DeskApp 的核心定位是"AI Agent 桌面管理器和伙伴"。管理器的一半已经建成（planner/worker 双模型、任务树、Agent 管理），伙伴的一半靠习惯工程补齐：

- **观察**：持续、低侵扰地感知使用者的电脑使用过程（前台应用、窗口标题、浏览网页、文件活动、DeskApp 会话）。
- **理解**：把原始事件流压缩成每日摘要，再从摘要中提炼出可复用的"习惯卡片"（时间例程、操作序列、上下文偏好）。
- **行动**：基于习惯主动服务——晨间简报、例程一键执行、偏离提醒、重复工作流自动化提案。
- **成长**：宠物与使用者的"懂你指数"随习惯积累而成长，形成情感连接。
